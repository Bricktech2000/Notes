## Pair

**definition** a _pair_ is an ordered collection containing exactly two elements

**definition** _formally in my [[math notation]]_ a [[pair]] is a [[set theory]]etical [[function]] that takes a [[boolean]] index and returns the element at that index

**notation**

**`P = {f, t}`**, where

- **`P`** is a [[pair]]
- **`t`** and **`f`** are the elements of **`P`** such that **`P^.__ = f /\ P^.^^ = t`**

**properties**

_equality_ **`{a, b} = {c, d} == a = c /\ b = d`**

_negation_ **`.{a, b} == {.a, .b}`**

## Pair Inverse

_switches around the two elements of a [[pair]]_

**equiv** _[[relation#inverse relation]]_

**notation** **`P {+} *`**

**definition** **`P {+} *`**

> **note** --- me; likely has no [[conventional math notation]] equivalent

**properties**

**`P {+} * == {P ^^, P __}`**

**`(P {+} *) {+} * = P`** for all [[pair]] **`P`**

**examples**

> **example** **`{e, i} {+} * = {i, e}`**
